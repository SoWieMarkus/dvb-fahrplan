# Release notes 2.0 (versionCode 7)

Paste into Play Console → release → "Release notes". Max. 500 characters per language.

<de-DE>
Komplett neu gebaut!
• Ein Bildschirm für alles: nur Start eingeben = Live-Abfahrten, mit Ziel = Verbindungen
• Abfahrten und Fahrten aktualisieren sich live, inkl. Verspätungen und Ausfällen
• Frühere und spätere Verbindungen
• Fahrtverlauf mit Live-Position auf der Karte
• Favoriten und gespeicherte Strecken
• Verkehrsmeldungen direkt an den betroffenen Abfahrten
• Neues Design mit Dunkelmodus
</de-DE>

<en-US>
Completely rebuilt!
• One screen for everything: enter a start stop for live departures, add a destination for connections
• Departures and trips update live, including delays and cancellations
• Earlier and later connections
• Trip view with the vehicle's live position on a map
• Favorite stops and saved routes
• Service changes right at the affected departures
• New design with dark mode
</en-US>
